# פיתוח יחידה — קורס דיגיטלי

## אופן שימוש
```
/פיתוח-יחידה [COURSE/unit-XX]
```
דוגמה: `/פיתוח-יחידה Cyber-Youth/unit-05`

ה-`$ARGUMENTS` מכיל את הנתיב היחסי לתיקיית היחידה תחת `courses/`.

---

## שמונה שלבי הפיתוח

עבוד לפי הסדר. לאחר כל שלב — דווח שורה קצרה ("שלב X הושלם — [מה נוצר]") והמשך מיד לשלב הבא, אלא אם חסר מידע קריטי מהמשתמש.

---

### שלב 1 — קריאת קבצי ההנחיות

קרא את כל הקבצים הבאים בסדר זה:
1. `CLAUDE.md` — שורש הפרויקט (עקרונות כלליים)
2. `courses/[COURSE]/CLAUDE.md` — הקשר ספציפי לקורס
3. `courses/[COURSE]/unit-template.md` — מבנה יחידה תקני + קבצי ייצור
4. `courses/[COURSE]/syllabus.md` — תוכנית הלימודים
5. `courses/[COURSE]/assets/audiences/*.md` — פרופיל קהל יעד אם קיים

**מה לחלץ:** עקרונות פדגוגיים, פלטת צבעים (CSS variables), מטפורה מרכזית, קונבנציות טכניות (SCORM, RTL, ספריות), מבנה מסכים קבוע, סוג פעילות לפי יחידה.

---

### שלב 2 — קריאת מפרט היחידה

חפש בתיקיית `courses/$ARGUMENTS/` קבצים שמתארים את תוכן היחידה:
- קובץ `.docx` — המסמך המקורי (ייתכן שאינו קריא ישירות)
- קובץ `.md` — גרסת טקסט של המפרט
- הפרק המתאים ב-`syllabus.md`

**אם הקובץ לא קריא** (docx/pdf) — בקש מהמשתמש להדביק את התוכן המרכזי, או פעל לפי תיאור ב-syllabus בלבד.

**מה לחלץ:** נושאים מרכזיים, מושגים טכניים שחייבים להופיע, דוגמאות ספציפיות, רמת הסבר מצופה, קשרים ליחידות אחרות.

---

### שלב 3 — פיתוח היחידה (index.html)

בנה `index.html` לפי המבנה הקבוע מ-unit-template.md:

- **CSS:** העתק ממה שנכתב לאחרונה ביחידות הקודמות — לא מיחידה 1
- **פלטת צבעים:** לפי CSS variables מ-CLAUDE.md של הקורס
- **מטפורה:** כל מסך, כל דוגמה — מחוברים למטפורה המרכזית
- **סוג פעילות** לפי טבלת unit-template.md (גרירה / טרמינל / תרחיש)
- **SCORM 1.2:** scormInit + scormComplete בסיום quiz
- **RTL:** `<html dir="rtl" lang="he">` | LTR רק לקוד ופלט טרמינל

**מבנה מסכים:**
```
S0 HOOK → S1 וידאו → S2 יעדי למידה → S3–S(n-2) תוכן → S(n-1) quiz (3 שאלות) → Sn סיכום + מה הבא
```

**פלט:** `courses/$ARGUMENTS/index.html`

---

### שלב 4 — אימות מול מפרט המקורי

חזור למה שנמצא בשלב 2 ובדוק ש-index.html כולל:
- [ ] כל הנושאים המרכזיים מהמפרט
- [ ] כל מושג טכני — הגדרה + דוגמה קונקרטית + רלוונטיות לסייבר
- [ ] קישור לחומר מיחידות קודמות (לא מתחיל מאפס)
- [ ] מטפורה מרכזית מופיעה לאורך כל הדרך — לא רק בפתיחה
- [ ] כל מסך מכיל לפחות שני אלמנטים ויזואליים/אינטראקטיביים (לא פסקה בלבד)

**אם חסר תוכן** — עדכן את index.html לפני שמתקדמים.

### שלב 5 — תסריט סרטון הפתיחה (script-heygen.md)

כתוב תסריט לשחקן HeyGen (מגיש AI):

**מבנה:**
```
# תסריט HeyGen — יחידה [X]
## [שם היחידה]
**משך משוער:** X:XX דקות
**מטרה:** [מה הסרטון מסביר]
**הערות במאי:** הוראות ב-[סוגריים] — לא לקרוא בקול

---

## פתיחה — 30 שניות
[רקע: תיאור ויזואלי לסצנת הפתיחה]
טקסט הנאום בשורות קצרות...

## [שם נושא] — X שניות
[מעבר: ...]
...

## סיום — 20 שניות
...
```

**כללים לשפה:**
- עברית ישירה, מדוברת, קצרה בשורות — לא פסקאות
- שפה של נוער 13–18, לא אקדמית
- כל סצנה פותחת עם קישור למטפורה
- הפסקות ב-`[הפסקה — X שניות]`

**פלט:** `courses/$ARGUMENTS/script-heygen.md`

### שלב 6 — פרומפטים ליצירת תמונות (script-codex.md)

כתוב תיאורי פרומפט ליצירת תמונות סטילס לסרטון:

**כמות:** 3–6 תמונות לכל יחידה. תמיד כולל טיזר פתיחה (2–3 תמונות). קליפים נוספים — רק כשיש ערך ויזואלי ברור שקשה להסביר בטקסט.

**מבנה לכל תמונה:**
```
### תמונה N — [תיאור קצר]
**קובץ:** 0N_שם_תיאורי.png
**שימוש ב:** סצנת [X] בתסריט
**תיאור:** [מה בתמונה — בעברית]
**פרומפט:** [English — cinematic 16:9, dark cyberpunk city, neon cyan/blue, dramatic lighting, described scene...]
```

**סגנון קבוע לכל הפרומפטים:**
`...cyberpunk cityscape at night, neon cyan and blue glows, dark atmosphere, cinematic dramatic lighting, 16:9, high quality digital art`

**פלט:** `courses/$ARGUMENTS/script-codex.md`

### שלב 7 — הנפשות Kling (script-kling.md)

כתוב תיאורי הנפשה לכל תמונה מ-script-codex.md:

**כלל:** כל קליפ = 5 שניות. סצנה ארוכה מחולקת לקליפים ברצף (1.1, 1.2, ...).

**מבנה:**
```
# הנפשות ל-Kling — יחידה [X] — [שם]

> כל קליפ נוצר מתמונה אחת + תיאור תנועה.
> משך מומלץ: 5 שניות.

---

## [שם הקטע]

### קליפ X.Y — [תיאור קצר]
**קובץ:** [שם_קובץ.png מ-script-codex.md]
**משך:** 5 שניות
**הנפשה:** [English — camera movement + what moves + direction + speed. Cinematic, slow, dramatic.]

---
```

**בסוף הקובץ** — טבלת הרכבה:
```
## סדר הרכבה ב-HeyGen

| קליפ Kling | משך | מתאים לסצנת תסריט |
|------------|-----|-------------------|
| X.Y + X.Z  | 10 שנ' | [שם הסצנה] |
| **סה"כ** | **~X שנ'** | |
```

**פלט:** `courses/$ARGUMENTS/script-kling.md`
