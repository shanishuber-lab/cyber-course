# קליפ 2 — תסריט HeyGen
# DevTools לעומת curl | ~40 שניות

## להדביק ב-HeyGen — טקסט בלבד, ללא עיצוב

---

הדפדפן שלכם עושה בדיוק את מה שcurl עושה.
בכל פעם שנכנסים לאתר — נשלחת בקשת HTTP, ומגיעה תגובה.

ההבדל היחיד?
הדפדפן מסתיר מכם את השיחה.

אם פותחים DevTools ועוברים ללשונית Network,
רואים שם בדיוק אותם headers שcurl מחזיר בטרמינל.

content-type, server, status code — הכל זהה.

curl פשוט לא מסתיר כלום.
זה הכלי שמראה לכם מה באמת עובר.

---
