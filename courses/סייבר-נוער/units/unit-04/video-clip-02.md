# קליפ 2 — DevTools לעומת curl
## יחידה 4 | הקלטת מסך | ~40 שניות

---

## מטרה
להראות שמה שהדפדפן עושה מאחורי הקלעים — curl עושה בגלוי.  
הצופה מבין שהדפדפן לא "יודע" משהו שהם לא יודעים — הוא פשוט מסתיר את השיחה.

---

## מה לצלם — צעד אחד אחר צעד

| שניות | פעולה |
|--------|--------|
| 0–4 | Chrome פתוח ב-`https://example.com`. הדף נראה "רגיל". |
| 4–8 | פתיחת DevTools: F12 → לשונית **Network**. |
| 8–13 | רענון הדף (Ctrl+R / Cmd+R). רשימת הבקשות מתמלאת. |
| 13–20 | לחיצה על הבקשה הראשונה (`example.com`). גלילה ל-**Response Headers**. זום על: `content-type`, `server`, `content-length`. |
| 20–22 | מעבר מהיר — Alt+Tab לטרמינל. |
| 22–30 | הקלדה: `curl -I https://example.com` → Enter. |
| 30–38 | הפלט: `HTTP/2 200`, `content-type: text/html`, `server: ECS (nyb/1D18)`. |
| 38–40 | Split screen: DevTools משמאל, טרמינל מימין. שתי העמודות מראות **אותם headers**. |

---

## הגדרות צילום

- **Split screen בסיום:** חלק ה-DevTools ב-Chrome, חלק טרמינל — לאורך (vertical split)
- **גודל גופן:** DevTools Developer Tools > Settings > Font size להגדיל ל-14+
- **הדגשה:** אפשר לצייר מסגרת/חץ על ה-headers הזהים משני הצדדים בעריכה
- **קצב:** לא ממהרים — צופה צריך לספוג שהכתובות זהות

---

## הערות עריכה

- כתוביות מוצעות:
  - בזמן DevTools: **"מה שהדפדפן רואה"**
  - בזמן curl: **"מה שcurl מראה"**
  - בזמן split: **"אותה שיחה בדיוק"**
- חץ מקשר או highlight על header משותף (למשל `content-type`) בשני הצדדים
